# 暮港行动 Dusk Harbor

一款直接在浏览器中运行的 3D 战术射击游戏。玩家加入蓝队，在黄昏时分的七号码头与红队电脑对手进行团队死斗。率先达到目标击杀数，或在倒计时结束时领先的队伍获胜。

游戏构建产物是一个不到 300 KB 的 `index.html`。贴图由 Canvas 程序化生成，音效由 Web Audio API 实时合成；运行时仅从内容分发网络（Content Delivery Network，CDN）加载 three.js r128 和 Google Fonts。

## 开始游戏

### 直接打开

使用 Chrome、Edge 或 Firefox 打开仓库根目录的 `index.html`。首次加载时需要联网下载 three.js 和字体资源。

### 启动本地服务器

如果浏览器限制本地文件访问，请在仓库根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。页面正常加载并显示游戏主菜单，即表示启动成功。

## 了解游戏内容

- 支持每队 3、5、6 或 8 人，蓝队包含玩家。
- 提供新兵、老兵、精锐和传奇 4 档电脑对手强度。
- 包含 VX-7 突击步枪、LR-338 狙击枪、P9 手枪、战术刀和 FRAG-12 破片手雷。
- 电脑对手具有寻路、视野判定、声音感知和队友报点能力。
- 支持桌面端键鼠操作，也支持手机和平板横屏触控。
- 画质、灵敏度、视野和音量等设置保存在浏览器的 `localStorage` 中。

## 使用桌面端操作

| 按键 | 作用 |
|---|---|
| `W`、`A`、`S`、`D` | 移动 |
| 鼠标 | 瞄准 |
| 左键 | 开火 |
| 右键 | 瞄准；狙击枪开镜并切换两档倍率 |
| `Space` | 跳跃 |
| `Ctrl` 或 `C` | 下蹲 |
| `Shift` | 静步 |
| `R` | 换弹 |
| `1`~`4` 或滚轮 | 切换武器 |
| `Q` | 切回上一把武器 |
| `G` | 快速投掷手雷 |
| 按住 `Tab` | 查看计分板 |
| `B`（阵亡时） | 切换下一条命的主武器 |
| `Esc` | 暂停 |

手机和平板请使用横屏模式：左半屏拖动控制移动，右半屏拖动控制视角，屏幕按钮用于开火、瞄准、跳跃、下蹲、换弹、切换武器和投掷手雷。

如果浏览器不允许锁定鼠标，游戏会自动切换到兼容模式，仍可使用 `Esc` 暂停。

## 了解胜负规则

每局比赛可选择 5、8 或 12 分钟。队伍规模与目标击杀数对应如下：

| 每队人数 | 目标击杀数 |
|---:|---:|
| 3 | 30 |
| 5 | 50 |
| 6 | 60 |
| 8 | 75 |

角色阵亡 4 秒后复活，复活后获得 2.5 秒出生保护；开火会立即解除保护。

## 修改并构建游戏

项目不需要安装第三方构建依赖。修改 `src/` 中的文件后，在仓库根目录运行：

```bash
python3 build.py
```

脚本会按文件名顺序读取 `src/*.js`，并与 `src/00_head.html` 合并后覆盖根目录的 `index.html`。后面的模块可以使用前面模块定义的内容。

构建完成后，终端会输出生成文件的路径和大小。提交代码前请同时提交源文件和重新生成的 `index.html`。

## 部署到 GitHub Pages

仓库公开或 GitHub 方案支持私有仓库 Pages 时，可以直接部署根目录中的静态文件：

1. 打开仓库的 **Settings > Pages**。
2. 在 **Build and deployment** 中将 **Source** 设为 **Deploy from a branch**。
3. 选择 `main` 分支和 `/ (root)` 目录，然后保存。
4. 等待部署完成，访问 `https://<用户名>.github.io/<仓库名>/`。

如果页面只有空白背景，请先打开浏览器开发者工具检查网络请求，并确认当前网络可以访问 cdnjs 和 Google Fonts。

## 了解技术实现

- 渲染：three.js r128、ACES 色调映射、PCF 软阴影和基于天空的环境反射。
- 性能：游戏根据运行帧率动态调节渲染分辨率。
- 导航：0.5 米网格的多层导航网格、A* 寻路和路径拉直。
- 感知：电脑对手会响应视野、脚步声、枪声、爆炸和队友报点。
- 资源：贴图和音效均在运行时生成，不包含额外的图片或音频素材。
